# 🥗 Fat Loss Calculator

A smart fat-loss meal planner that automatically calculates food portions to match your macro targets and calorie deficit goals.

## ✨ Features

- **Smart BMR/TDEE Calculation**: Uses Mifflin-St Jeor or Katch-McArdle formulas
- **Flexible Macro Distribution**: Set by percentages or grams per kg body weight  
- **Intelligent Food Optimization**: Advanced algorithm finds optimal food portions
- **17+ Food Database**: Common foods with realistic portion ranges
- **Mobile Friendly**: Responsive design works on all devices

## 🚀 How to Use

1. **Enter your stats** (age, weight, height, activity level, deficit %)
2. **Set macro targets** (carbs/protein/fat distribution)
3. **Select foods** you want to include in your meal plan
4. **Generate plan** - get optimized portions for each food
